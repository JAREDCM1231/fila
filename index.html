🐢 ¿Qué es una Queue (Cola)?

Una Queue (cola en español) es una estructura de datos que funciona bajo el principio FIFO: First In, First Out, es decir, el primero en entrar es el primero en salir.

🚪 Primero en entrar ➡️ 🎉 Primero en salir
SALIDA ← A B C D ← ENTRADA

📌 Analogía del mundo real

Imaginate una fila en un supermercado. La primera persona que se formó en la caja es la primera en ser atendida y la primera en salir de la fila. Si llega una persona nueva, se pone al final y le toca esperar su turno. Nadie salta la fila: se respeta el orden de llegada. Exactamente así funciona una Queue en programación: los elementos se agregan al final y se sacan desde el frente, respetando el orden en que llegaron.

⚙️ Operaciones principales

➕

Enqueue

Agrega un elemento al final de la cola. Es como cuando una persona se pone al final de la fila.

➖

Dequeue

Elimina y devuelve el primer elemento de la cola. Es como cuando la persona que estaba al frente de la fila es atendida y se va.

👀

Peek

Permite consultar cuál es el primer elemento sin eliminarlo. Como mirar quién está al frente de la fila sin que esa persona se mueva.

⚡ Análisis de Rendimiento

La eficiencia de una Queue depende de la implementación utilizada. En este proyecto se utiliza un Array de JavaScript con los métodos push() y shift().

Operación Complejidad Explicación
Enqueue O(1) Agregar al final con push() es una operación constante, ya que solo se añade al final del array sin mover otros elementos.
Dequeue O(n) Eliminar con shift() requiere desplazar todos los elementos restantes una posición hacia la izquierda, lo que toma tiempo proporcional al número de elementos.
Peek O(1) Acceder al primer elemento con queue[0] es instantáneo, ya que solo se lee una posición conocida del array.
Búsqueda O(n) En el peor caso, hay que recorrer todos los elementos hasta encontrar el deseado o confirmar que no está.

✅ ¿Cuándo utilizar una Queue?

Una Queue es ideal cuando necesitas procesar elementos en el orden exacto en que llegaron. Se utiliza mucho en sistemas de turnos, colas de impresión, procesamiento de solicitudes en servidores, algoritmos de recorrido en amplitud (BFS), y en cualquier situación donde el orden de llegada debe respetarse.

❌ ¿Cuándo NO utilizar una Queue?

Una Queue no es la mejor opción cuando necesitas acceder rápidamente a un elemento en cualquier posición, cuando necesitas buscar constantemente elementos arbitrarios, o cuando requieres acceso directo por índice. En esos casos, un Array o un Map serían más eficientes.

💻 Código Base

A continuación se muestra la implementación de la Queue utilizada en este simulador. Se utiliza un Array de JavaScript como estructura subyacente. 

// Implementación de una Queue (Cola) usando Array de JavaScript

const queue = [];

// Enqueue: agrega un elemento al final de la cola
function enqueue(element) {
    queue.push(element);
}

// Dequeue: elimina y devuelve el primer elemento
function dequeue() {
    return queue.shift();
}

// Peek: consulta el primer elemento sin eliminarlo
function peek() {
    return queue[0];
}

// Verificar si la cola está vacía
function isEmpty() {
    return queue.length === 0;
}

// Tamaño de la cola
function size() {
    return queue.length;
}

🌎 Aplicaciones en el Mundo Real

🛒

Filas de supermercado y atención al cliente

Dónde: Supermercados, bancos, restaurantes fast-food.

Cómo: Cada persona que llega se pone al final de la fila (enqueue). Cuando un cajero se desocupa, atiende a la persona que está al frente (dequeue). Se respeta el orden de llegada para ser justo con todos.

🖨️

Cola de impresión

Dónde: Oficinas, universidades, cualquier entorno con impresoras compartidas.

Cómo: Cuando varios usuarios envían documentos a la misma impresora, cada trabajo se agrega a una cola. La impresora procesa los documentos en el orden exacto en que fueron enviados, imprimiendo primero el que llegó primero.

🌐

Procesamiento de solicitudes en servidores web

Dónde: Servidores de páginas web, bases de datos, APIs.

Cómo: Cuando múltiples usuarios envían peticiones a un servidor al mismo tiempo, las solicitudes se encolan y se procesan en orden de llegada. Esto garantiza que cada usuario reciba respuesta de manera justa y ordenada.

Primero entra → Primero sale

A ➡️ B ➡️ C ➡️ D

A sale primero · los nuevos entran por D

🥞 LIFO (Pila)

Último entra → Primero sale

D C B A
